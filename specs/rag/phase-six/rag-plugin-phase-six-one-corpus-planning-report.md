# DSH RAG 插件第六阶段 6.1 完整语料规划报告

本文记录上下文前缀在完整语料上的无 LLM 成本规划。原始统计见 [`data/contextual-prefix-corpus-planning-summary.json`](data/contextual-prefix-corpus-planning-summary.json)，质量评测的有界输入对照见 [`data/contextual-prefix-quality-evaluation-summary.json`](data/contextual-prefix-quality-evaluation-summary.json)。

## 方法

统计器读取、校验、摘要并计数五个完整语料，但不创建 SQLite、BM25、Exact 或 HNSW 索引，不加载 Dense encoder，也不调用生成模型。SciFact 与 MLQA 对全部文档分片；MLDR 与 T2Ranking 按文档 ID 摘要进行确定性抽样后估算分片级总量。T2Ranking 使用已有 100,001 分片切片校准，百分之一抽样估算为 98,455，误差为 -1.55%。

按 `context-prefix-v5` 计划逻辑，完整语料预计需要 1,063,758 个请求、1,473,764,143 个输入 token 和最多 245,199,051 个输出 token。以上是规划上界，不是实际账单。

## 有界质量子集成本

质量评测固定为 200 条真实查询和 11,273 个分片，低于 50,000 分片上限。章节窗口批处理需要 1,513,750 个输入 token；逐候选重复提交完整文档的估算值为 7,478,518，节省 79.7587%。

| 数据集 | 候选数 | 有界输入 token | 逐候选全文估算 | 节省率 |
| --- | ---: | ---: | ---: | ---: |
| SciFact | 193 | 173,908 | 178,289 | 2.46% |
| MLQA eng-zho | 204 | 160,329 | 177,212 | 9.53% |
| T2Ranking | 430 | 441,825 | 1,028,448 | 57.04% |
| MLDR-zh | 274 | 318,332 | 3,172,243 | 89.97% |
| MLDR-en | 343 | 419,356 | 2,922,326 | 85.65% |

## 结论

有界窗口对长文档有效，但短文档数据集几乎没有可压缩的重复上下文，导致总体节省率比 80% 验收线低 0.2413 个百分点。成本门槛未通过，不能把 79.7587% 四舍五入为通过。完整语料约 17.19 亿 token 的上界也不支持默认开启或全量生成。
