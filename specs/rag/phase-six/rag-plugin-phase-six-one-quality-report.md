# DSH RAG 插件第六阶段 6.1 真实质量评测报告

本文记录选择性上下文前缀在真实 qrels 子集上的质量结果。机器摘要见 [`data/contextual-prefix-quality-evaluation-summary.json`](data/contextual-prefix-quality-evaluation-summary.json)，盲复核摘要见 [`data/contextual-prefix-factual-review-summary.json`](data/contextual-prefix-factual-review-summary.json)。

## 评测设置

评测覆盖 SciFact、MLQA eng-zho、MLDR-zh、MLDR-en 和 T2Ranking，各 40 条查询，共 200 条。五个索引合计 11,273 个分片，均包含所选查询的全部相关文档和固定干扰文档。检索路径为 BM25、Exact Dense 和 Hybrid，`maxResults=20`、候选数 50、Reranker 关闭，BM25 统一使用 `mixed-zh-en-v1`。前缀模型不接收查询、qrels、检索分数或相关文档标记。

比较项为当前检索文本、确定性前缀、LLM 前缀仅用于 Dense、LLM 前缀同时用于 BM25 与 Dense。除 SciFact 外，确定性记录全部回退，因此其结果与当前检索文本相同。

## 完整混合集

下表列出各数据集主要的 Hybrid 结果；括号为相对当前检索文本的 nDCG@10 变化。

| 数据集 | 当前 Recall@10 | 当前 nDCG@10 | LLM Dense-only Recall@10 | LLM Dense-only nDCG@10 | LLM 双路 Recall@10 | LLM 双路 nDCG@10 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| SciFact | 89.17% | 78.57% | 81.67% | 75.41% (-3.16 pp) | 81.67% | 75.16% (-3.40 pp) |
| MLQA eng-zho | 85.00% | 74.64% | 82.50% | 71.68% (-2.96 pp) | 82.50% | 71.68% (-2.96 pp) |
| MLDR-zh | 97.50% | 91.88% | 97.50% | 92.01% (+0.13 pp) | 97.50% | 92.01% (+0.13 pp) |
| MLDR-en | 100.00% | 96.40% | 100.00% | 96.62% (+0.22 pp) | 100.00% | 96.62% (+0.22 pp) |
| T2Ranking | 90.11% | 87.27% | 90.11% | 87.97% (+0.70 pp) | 90.11% | 87.90% (+0.63 pp) |

T2Ranking、MLDR-zh 和 MLDR-en 的 Hybrid nDCG@10 有同方向小幅提升，但 Recall@10 没有提高。SciFact 与 MLQA 出现 2.96–3.40 个百分点的 nDCG@10 回退，并伴随 Recall@10 下降，因此未通过任一路最多下降 1 个百分点的保护线。

## 高歧义子集

当前检测器对应的高歧义查询中，没有任何数据集或检索路径相对确定性前缀获得至少 5 个百分点的 Recall@10 或完整证据覆盖率提升，观测到的最大提升为 0。SciFact 的 Dense 完整覆盖率从 75% 保持为 75%，Hybrid 从 75% 降至 70%；MLQA 的 Dense 和 Hybrid 完整覆盖率均从 85% 降至 80%；两个 MLDR 子集和 T2Ranking 的 Recall@10 与覆盖率不变。

该结果表明 `strict-v1` 选择出的分片虽然在语言形式上容易缺失上下文，但补充一句生成式前缀没有稳定转化为相关文档进入前十名。小幅排序变化不足以证明实际检索收益。

## 生成稳定性

五个数据集合计记录 1,470 个候选，其中 1,443 个得到前缀，27 个回退。26 个回退来自 T2Ranking 的 15% 候选比例限制，1 个来自连续两次 HTTP 503；按全部候选计算的成功率为 98.16%，低于 99% 门槛。若只计算实际进入生成预算的 1,444 个候选，成功率为 99.93%，但验收规则要求回退留在主结果中，因此不能用后者替代主成功率。

## 事实性盲复核

三个独立 agent 复核 100 条记录，不接触方案名、检索分数或选择原因。样本包含全部新增命中关联前缀、全部明显回退关联前缀、全部 27 条回退记录，以及确定性抽取的其余成功前缀。27 条无生成内容的回退记录记为不适用；73 条真实前缀中 70 条通过、3 条失败，事实性通过率为 95.89%，低于 99% 门槛。

三条失败均为原文未支持的具体化：把未注明地点的回忆写成“东北年俗”，加入原文没有出现的“末法”判断，以及从外部常识补入“1912 年 4 月 14 至 15 日”。未发现关键词堆叠，但这些错误说明短前缀仍会引入检索语料之外的事实。

## 索引 token

Dense 输入 token 增幅为 0.69%–1.49%，BM25 与 Dense 双路模式的 BM25 token 增幅为 0.76%–1.32%，均低于 10% 门槛。该门槛通过，但不能抵消质量和事实性失败。

## 结论

真实评测不支持保留上下文前缀索引能力。高歧义主指标没有达到最低增益，SciFact 和 MLQA 超过回退保护线，全部候选成功率与事实性通过率也未达标。6.1 的产品索引接入应撤回；候选统计、成本规划和评测工具可以保留，用于以后在更可靠的生成策略或更精确的候选检测器出现时重新验证。
