# DSH RAG 插件第六阶段上下文感知检索 Pilot 报告

## 1. 结论

上下文感知前缀在固定的 60 条构造样本上显著改善检索，但本 Pilot **不通过正式实现门槛**。LLM 三次运行的平均完整证据覆盖率从基线的 52.78% 提高到 96.67%，Recall@10 从 59.17% 提高到 96.67%；与此同时，平均索引 token 增加 29.49%，超过 25% 上限，第三次生成成功率为 98.61%，低于每次运行至少 99% 的要求。盲复核还发现 54/60 样本带有明显模板化语料或措辞，15/60 样本的至少一轮前缀存在事实表达过度、实体未解析或时间表述不严谨。

本结果证明“为孤立分片补充文档上下文”在受控条件下具有潜力，但不能证明真实知识库具有同等收益。第六阶段停止生产实现，不修改 `retrievalText()`，不增加运行时前缀生成、前缀缓存或新的默认配置；当前标题、章节路径和正文组合继续作为默认检索输入。

机器可读结果见 [`data/contextual-retrieval-pilot-evaluation-summary.json`](data/contextual-retrieval-pilot-evaluation-summary.json)，固定样本见 [`data/contextual-retrieval-pilot-samples.jsonl`](data/contextual-retrieval-pilot-samples.jsonl)。实验协议和门槛见[详细技术方案](rag-plugin-phase-six-detailed-design.md#8-上下文感知检索-pilot)。

## 2. 实验设计

固定集合包含 60 条查询和 72 个预先确定的分片，代词指代、相对时间、同名实体、跨章节归属和弱标题结构各 12 条。每条查询在生成前固定相关分片和原文证据，不根据运行结果补样本或修改 qrels。

三种索引文本只改变写入 BM25 和 Dense 的文本，不改变分片边界、查询或 qrels：

1. **Baseline**：生产默认的标题、章节路径和正文组合。
2. **Deterministic**：带标签的标题、章节、来源版本和有效期，再接原始正文。
3. **LLM**：模型根据完整文档和目标分片生成最多 80 token 的上下文段落，再接原始正文；提示中不包含评测查询。失败项使用 deterministic 文本回退，并保留在主指标与失败统计中。

检索矩阵固定为 BM25、BGE-M3 Exact Dense 和两者的 Hybrid，`candidateCount=50`、`maxResults=10`、`rrfK=60`，关闭 Reranker 和相邻分片扩展。Dense 模型固定为 `onnx-community/bge-m3-ONNX@25b9af8e87a38eb120cfe87125383677b9cd309e`。前缀模型为 `gpt-5.6-sol`，通过 Responses API 以并发 4 独立生成三次；三次使用隔离缓存命名空间，没有复用前一次前缀。

## 3. 检索结果

下表先对每种输入的 BM25、Dense 和 Hybrid 指标取算术平均；百分点变化均基于未四舍五入值计算。

| 输入 | 完整证据覆盖率 | Recall@10 | nDCG@10 | MRR@10 | 索引 token 增幅 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Baseline | 52.78% | 59.17% | 42.75% | 38.99% | 0% |
| Deterministic | 60.56% | 67.22% | 45.93% | 40.32% | 8.84% |
| LLM 三次均值 | 96.67% | 96.67% | 93.69% | 93.24% | 29.49% |

Deterministic 相对 baseline 的完整覆盖率和 Recall@10 分别提高 7.78 和 8.06 个百分点，说明已有结构化元数据本身解释了一部分收益。LLM 相对 deterministic 仍分别提高 36.11 和 29.44 个百分点，相对 baseline 分别提高 43.89 和 37.50 个百分点。

三次 LLM 运行没有只保留最好结果：

| 运行 | 完整证据覆盖率 | Recall@10 | nDCG@10 | MRR@10 | 索引 token 增幅 | 生成成功率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| LLM-01 | 97.22% | 97.22% | 94.57% | 93.97% | 29.68% | 100% |
| LLM-02 | 97.78% | 97.78% | 94.99% | 94.84% | 29.40% | 100% |
| LLM-03 | 95.00% | 95.00% | 91.49% | 90.90% | 29.41% | 98.61% |

Baseline 和 deterministic 的重复结果一致。三次 LLM 运行的主指标都高于 deterministic，各召回方式的 nDCG@10 也没有相对 baseline 回退超过一个百分点。

## 4. 成本与失败

Baseline 使用 12,219 个索引 token，deterministic 使用 13,299 个；三次 LLM 运行分别使用 15,845、15,811 和 15,812 个，平均比 baseline 增加 29.49%。该成本不含生产化所需的模型部署、持久缓存、重试、迁移和全量重建运维，因此已经超过门槛的 Pilot 不继续扩大规模。

每次运行生成 72 个前缀，输入 token 均为 36,681，输出 token 分别为 5,365、4,927 和 5,214。累计生成延迟分别约为 235.4、296.9 和 405.1 秒；这些是各请求延迟之和，不等于并发执行的墙钟时间。第三次运行的 `weak-doc-11:target` 因 `token-limit` 回退到 deterministic 文本，使该次成功率降至 71/72；Pilot 没有隐藏或删除该样本。

## 5. 盲复核

复核模型为 `gpt-5.6-sol`。复核输入提供查询、qrels、文档元数据、正文和三次前缀，但不提供检索质量结果，避免让“指标提高”影响事实性判断。复核结果如下：

- 60/60 样本的 qrels 与原文证据一致。
- 60/60 前缀组没有直接引用评测查询。
- 45/60 样本的三轮前缀均通过事实性与指代精确性检查；其余 15 条至少一轮存在措辞过度、实体未解析或时间表述不严谨。
- 54/60 样本存在明显模板化语料或措辞，可能让前缀更容易把目标词推到相关分片，从而放大受控样本上的收益。

因此，96.67% 的平均完整覆盖率不能外推为生产质量。该集合适合验证机制能否改善人为制造的孤立分片歧义，不足以估计真实 Markdown、代码库文档或混合知识库中的净收益。

## 6. 门槛判定

| 门槛 | 结果 | 判定 |
| --- | --- | --- |
| 基线和 deterministic 重复结果一致 | 一致 | 通过 |
| 相对 baseline 主指标至少提高 5 个百分点 | 完整覆盖率 +43.89 pp，Recall@10 +37.50 pp | 通过 |
| 相对 deterministic 仍为正收益，且三次方向一致 | 三次均为正收益 | 通过 |
| 任一召回方式 nDCG@10 回退不超过 1 pp | 无超限回退 | 通过 |
| 平均索引 token 增幅不超过 25% | 29.49% | **不通过** |
| 每次前缀生成成功率不低于 99% | 最低 98.61% | **不通过** |

最终判定为 `stop-and-keep-current-default`。失败门槛不是唯一停止原因：盲复核确认样本模板偏差很强，即使放宽 token 或成功率限制，本 Pilot 仍不能单独支持生产默认值变更。

## 7. 后续条件

只有新的独立评测同时降低样本模板偏差、控制索引 token 增幅并证明稳定生成成功率，才值得重新提出正式实现。后续评测至少应使用真实文档切片、与检索查询独立编写的 qrels、未参与样本设计的复核者，并报告前缀事实性和端到端成本；在这些证据出现前，不进行完整语料前缀生成或向量重建。
