# DSH RAG 插件第六阶段 6.1 实施任务

## 1. 交付原则

本阶段完成了上下文前缀的离线规划、生成、缓存和真实评测。完整语料只运行无LLM的流式统计，不生成完整分片或索引；生成与向量评测使用冻结的真实有界子集。产品索引接入因验收失败撤回，默认建库和在线检索路径不会调用模型。

## 2. 优先级、依赖与成本

| ---: | --- | --- | --- | --- | --- |

| 2 | `strict-v1`候选检测与规划器 | P0 | 当前分片规则 | 2–3人日 | 完整语料流式扫描约数小时，不建索引、不调用LLM |
| 3 | 有界窗口、批量生成与预算执行 | P0 | 冻结计划 | 2–4人日 | 评测子集生成约1–4小时 |
| 4 | 前缀缓存和增量失效 | P0 | 生成协议、文档派生缓存 | 2–3人日 | 低至中 |

## 4. 基线与规划

### T0：固定数据、指标和成本口径

- 固定五个完整语料的文件摘要、文档数、格式和当前分片配置。
- 从已有 qrels 固定至少200条真实查询，每个数据集不少于30条；记录相关文档和证据范围。
- 固定第六阶段 baseline、deterministic 和 LLM Pilot 指标，禁止把构造样本作为6.1主质量结论。
- 定义生成输入 token、输出 token、索引 token、缓存节省、请求数和向量失效数的计算口径。
- 明确完整语料轨道不允许落盘完整分片，不允许构建SQLite、BM25、Exact或HNSW，也不允许LLM生成。

完成条件：样本和指标在任何前缀生成前冻结；所有输入具有摘要；报告模板能够区分规划估算、服务端实际计量和索引 token。

### T1：`strict-v1`候选检测器

- 实现中英文开头指代、承接表达、跨段引用、相对时间和弱结构组合规则。
- 缺少标题、普通代词和短文本不能单独触发。
- 输出命中信号、风险等级和稳定排序键。
- 对重复标题、大小写、Unicode、空章节、重叠分片和语言混合建立单元测试。
- 使用第六阶段60条构造样本检查规则覆盖，但不据此调整真实评测 qrels。

完成条件：检测器不访问网络或模型；相同输入顺序变化不改变每个 chunk 的判断和排序。

### T2：计划、窗口和预算预览

- 实现章节优先、段落回退的有限上下文窗口，保证目标 chunk 完整包含。
- 合并同文档、同章节、窗口重叠的候选，执行每请求 chunk 数上限。
- 实现候选比例上限、风险优先裁剪和确定性并列排序。
- 使用生成器 tokenizer 计算请求输入 token，生成计划和机器可读摘要。
- 计划包含预计缓存命中、预计生成 token 上界和预计 Dense 向量失效数。

完成条件：超出候选比例或 token 预算时在任何生成请求前失败或按显式策略裁剪；长文档不会按 chunk 重复输入全文。

## 5. 生成与缓存

### T3：生成协议与适配器

- 抽取可注入的`ContextualPrefixGenerator`，固定模型身份、token 计数和实际 usage 返回要求。
- 实现批量 JSON schema、chunk ID 集合校验、单前缀 token 上限和原文大段复制检测。
- 首个命令行适配器复用已验证的 OpenAI-compatible Responses API，不把厂商调用放入索引核心。
- 凭据通过现有 credentials 能力或环境变量读取，不进入产物。
- 实现取消、有限重试、累计预算预留和实际用量结算。

完成条件：缺少预算、凭据、usage或完整模型 revision时不发起请求；失败和重试 token 均进入统计。

### T4：前缀缓存与恢复

- 新增独立 SQLite 前缀缓存和内容寻址身份。
- 原子提交成功记录；失败记录可审计但不能命中为成功结果。
- 验证0%变化、局部正文变化、章节边界变化、模型变化、提示变化和检测器变化的失效矩阵。
- 中断后复用已提交批次，继续执行未完成计划。
- 记录缓存查询、命中、生成、回退、输入输出 token 和延迟。

完成条件：相同计划重复运行不调用生成器；局部变化只使受影响窗口失效；损坏记录明确失败。

## 6. 临时索引对照与撤回

### T5：格式5实验与撤回

- 临时评测索引验证格式5、SQLite schema 4、`dense`与`bm25-and-dense`两种目标，以及逐 chunk 状态和用量计数。
- 未选中或显式回退的 chunk 使用当前标题、章节路径和正文；前缀超出 Dense 上限时失败。
- 验证未选中分片命中现有向量缓存，已变化前缀只重算对应向量。
- 验收失败后删除正式`index`参数、manifest字段、SQLite列和运行时读取逻辑，恢复格式4与SQLite schema 3。

完成条件：默认构建无生成器副作用；正式索引不接受前缀记录；返回证据和检索输入保持第六阶段行为。

## 7. 评测

### T6：完整语料无 LLM 规划

- 对完整SciFact、MLQA、MLDR-en、MLDR-zh和2,303,643篇T2Ranking运行流式统计器。
- 报告实际或估算分片数、各信号命中、候选比例、裁剪数量、批次合并比例和 token 上界；使用确定性文档抽样时必须同时记录完整文档数、抽样模数和实际分片文档数。
- 对T2Ranking 100k已构建切片比较估算与实际分片数，公开估算误差。
- 只保留累计统计和有限诊断样本，不落盘完整候选或分片集合。
- 不生成前缀、不加载Dense encoder，不创建完整SQLite、BM25、Exact或HNSW索引。

完成条件：五个完整语料都有机器摘要；候选总量和成本上界可以在生成前审核；报告不得把估算 token 写成实际账单。

### T7：真实质量与增量成本

- 为冻结的至少200条真实查询构造qrels完整的分层子集，每个数据集最多10,000个分片、合计最多50,000个分片。
- 已有匹配配置的索引和向量缓存只读复用；缺少产物时只构建有界子集，不重新构建任一完整数据集。
- 在有界子集上生成一次前缀，复用结果比较baseline、deterministic、Dense-only和BM25加Dense。
- 分别运行BM25、Exact Dense和Hybrid，关闭Reranker与相邻扩展。
- 输出完整混合集和高歧义子集的证据覆盖、Recall@10、nDCG@10和MRR@10。
- 测量相对逐chunk全文输入的生成输入节省、索引token增幅、构建时间、RSS和向量失效。
- 运行冷构建、0%、约1%、约10%变化和提示升级场景。
- 盲复核全部新增命中、明显回退、回退记录和随机成功前缀。

完成条件：生成输入至少节省80%；索引token总增幅不超过10%；高歧义子集主指标提高至少5个百分点；完整混合集任一路nDCG@10回退不超过1个百分点；生成和事实性通过率均不低于99%。

## 8. 收尾

### T8：文档、快照和验收

- 编写候选规划、生成成本、真实质量、增量成本和6.1总验收报告。
- 更新包README、公共JSDoc、CLI帮助、索引格式说明和受影响双语文档，明确产品接入撤回。
- 为非平凡实现增加Agent Note；模型可见结果未变化时明确说明不需要新工具快照，若输出变化则更新真实Loader快照。
- 运行相关逐文件100%覆盖率、真实小型生成烟测、真实BGE-M3烟测、`typecheck`、`lint`、`doc-sync`、`hygiene`和`git diff --check`。
- 检查完整语料、计划原文、生成缓存、模型响应、向量、索引、凭据和本机绝对路径不进入提交范围。
- 未得到用户明确指令时不commit、不push。

完成条件：每个概要门槛都有机器摘要、测试或报告证据；未通过的索引接入不存在于产品配置、格式、SQLite或运行时路径。

## 9. 建议提交拆分

以下拆分只描述评审边界，不代表允许自动提交：

1. 候选检测、计划格式和预算预览。
2. 有界批量生成器、前缀缓存和失败恢复。
3. 临时索引对照、向量复用和撤回验证。
4. 完整语料规划结果、真实质量评测和验收报告。

## 10. 明确暂缓

- 不把上下文前缀默认开启，不自动迁移既有索引。
- 不为评测构建完整数据集索引，不对完整五语料调用LLM或重建全部向量。
- 不支持无预算上限的生成，不支持逐chunk全文输入。
- 不实现在线生成、在线索引更新、HNSW原地修改或后台常驻生成服务。
- 不实现通用事实核验模型、RAPTOR、GraphRAG或实体图谱。
