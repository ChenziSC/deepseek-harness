# DSH RAG 插件第六阶段 6.1 验收报告

## 1. 结论

6.1 完成了完整语料成本规划、有限真实语料生成与检索评测、100 条盲复核和增量成本验证，但没有通过发布门槛。产品索引接入已撤回；正式索引保持格式 4、SQLite schema 3 和现有检索输入，不接受生成前缀记录，也不会调用生成模型。候选检测、流式统计、有界计划、生成缓存和评测工具保留，供以后验证改进方案。

本轮没有为任何完整数据集构建索引。质量评测只构建 11,273 个分片，并使用 200 条真实查询。

## 2. 门槛结果

| 门槛 | 实测 | 结果 |
| --- | ---: | --- |
| 有界输入相对逐候选全文节省至少 80% | 79.7587% | 失败 |
| Dense 或 BM25 索引 token 增幅不超过 10% | Dense 最大 1.49%，BM25 最大 1.32% | 通过 |
| 高歧义 Recall@10 或完整覆盖率提升至少 5 pp | 最大 0 pp | 失败 |
| 任一路 nDCG@10 回退不超过 1 pp | SciFact 与 MLQA 回退约 2.96–3.40 pp | 失败 |
| 全部候选生成成功率至少 99% | 98.16% | 失败 |
| 前缀事实性至少 99% | 95.89% | 失败 |

Hybrid nDCG@10 在 MLDR-zh、MLDR-en 和 T2Ranking 分别提高 0.13、0.22 和 0.70 个百分点，但三个数据集的 Recall@10 都没有提高。这些小幅排序收益不足以抵消 SciFact、MLQA 的明显回退以及事实性失败。

## 3. 成本与增量行为

完整五语料预计包含约 1,055 万个分片和 136 万个候选，生成计划上界约为 14.74 亿输入 token 与 2.45 亿输出 token。该结果来自无 LLM 流式规划，不是实际账单；它说明完整语料生成不具备可接受的默认成本。

有限 SciFact 子集的缓存实验中，0% 变化没有生成调用或向量编码；约 1% 文档变化只重新生成 2 个前缀并编码 14 个向量；约 10% 变化重新生成 20 个前缀并编码 146 个向量。提示版本升级会使 193 个候选全部失效，预计重新消耗 173,908 输入 token 和最多 39,760 输出 token，因此按约束只完成计划而未执行生成。详细结果见[增量成本报告](rag-plugin-phase-six-one-incremental-cost-report.md)。

## 4. 质量与事实性

真实评测覆盖 SciFact、MLQA eng-zho、MLDR-en、MLDR-zh 和 T2Ranking，每个数据集 40 条查询。高歧义子集没有达到最低质量增益；SciFact 和 MLQA 的 Hybrid nDCG@10 超过允许回退。详细指标见[真实质量评测报告](rag-plugin-phase-six-one-quality-report.md)。

三个独立 agent 盲复核 100 条记录，其中 27 条回退记录不适用；73 条真实前缀中 70 条通过、3 条失败。失败内容分别引入原文没有支持的“东北”、“末法”和“1912 年 4 月 14 至 15 日”，证明生成前缀可能把外部推断写入检索输入。

## 5. 最终保留范围

保留：

- `contextual-statistics` 的完整语料流式候选与成本统计；
- `contextual-plan` 的有限语料计划与预算预览；
- `contextual-generate` 的显式离线生成、预算控制和独立缓存；
- 真实质量、事实性和增量成本评测脚本与机器摘要。

撤回：

- `index` 的上下文前缀参数；
- manifest 与 SQLite 的上下文前缀字段；
- BM25 或 Dense 正式索引输入中的生成前缀；
- 格式 5 与 SQLite schema 4 升级。

重新提出产品接入前，新的方案必须同时改善候选精度、事实约束和跨数据集检索稳定性，并重新通过全部门槛；“默认关闭”不能替代验收。

## 6. 最终验证

- 相关包测试与定向覆盖率：32个文件通过、1个文件按环境跳过，561个测试通过、2个测试跳过；纳入范围的statement、branch、function和line覆盖率均为100%。
- 真实Loader的`knowledge-search`快照通过；示例索引已用当前构建器重新生成，manifest为格式4、SQLite为schema 3，且不包含上下文前缀字段。
- 本地缓存的真实BGE-M3小型烟测通过，未访问网络。
- `pnpm run typecheck`、`pnpm run lint`、`pnpm run doc-sync`、`pnpm run hygiene`和`git diff --check`通过。

原始前缀、模型响应、生成缓存、向量、实验索引和包含本机绝对路径的日志仍位于忽略目录，不属于交付文件。
