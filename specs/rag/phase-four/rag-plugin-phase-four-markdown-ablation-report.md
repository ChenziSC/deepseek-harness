# DSH RAG 插件第四阶段 Markdown 分片消融报告

## 1. 结论

T8 已完成。结构分片的结果是混合收益，不能表述为普遍提高检索质量：BM25 的 MRR@10 提高 3.00 个百分点、nDCG@10 提高 2.28 个百分点，但 Dense 和 Hybrid 的两项指标均下降约 1.5 至 2.0 个百分点。三种召回方式的平均 nDCG@10 只下降 0.23 个百分点，同时前五条结果的平均上下文 token 减少 32.6%，完整证据覆盖率提高 2.67 个百分点。因此保留 Markdown 结构分片及其默认地位，但结论限于“减少返回上下文并保留总体质量”，不宣称它对所有召回方式都有排序收益。

相邻扩展不改变排名。它使三种召回方式的平均完整证据覆盖率从 88.0% 提高到 92.0%，单条命中及其上下文的完整率从 73.33% 提高到 78.67%，但平均返回 token 从 422.5 增加到 747.7，增幅 77.0%。收益主要来自 BM25 跨块问题和 Hybrid 代码块问题，Dense 的完整证据覆盖率没有提高。该结果证明相邻扩展存在窄场景正收益，也证明其成本较高；保留 `adjacentChunkCount` 配置和当前质量优先默认值，token 预算敏感的部署应设为 `0`。

## 2. 固定输入

- Git revision：`955a9acb56acfbc9b0c7ff3760550d6819fb2f75`。
- 语料：20 个真实 Markdown 文件，文件清单及逐文件摘要见 [`markdown-ablation-files.json`](data/markdown-ablation-files.json)。
- 查询：25 条人工核验样本，`heading`、`section-body`、`code-block`、`cross-chunk` 和 `duplicate-heading` 各 5 条，见 [`markdown-ablation-samples.jsonl`](data/markdown-ablation-samples.jsonl)。
- 分片参数：`maxTokens=128`、`overlapTokens=24`。
- 检索：BM25、BGE-M3 q8 Exact Dense 和 Hybrid，Reranker 关闭。
- 排名指标使用前 20 条命中；上下文完整率和 token 数使用产品默认的前 5 条命中。相邻扩展组由提供方直接以 `maxResults=5` 查询，避免前 20 条中的相邻分片抑制本应附加给前 5 条的邻居。
- 每条样本的必需短语均存在于固定 revision 的相关文档中。机器可读构建和逐组结果见 [`markdown-ablation-evaluation-summary.json`](data/markdown-ablation-evaluation-summary.json)。

## 4. 结构分片结果

下表比较 Token 窗口与关闭相邻扩展的 Markdown 结构分片。证据完整率表示前五条相关文档命中的正文并集包含全部必需短语；单命中完整率要求一个命中及其局部上下文独立包含全部短语。

| 召回 | Token MRR@10 | Markdown MRR@10 | Token nDCG@10 | Markdown nDCG@10 | 完整证据变化 | 单命中变化 | token 变化 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| BM25 | 0.9300 | 0.9600 | 0.9477 | 0.9705 | 76% → 84% | 68% → 72% | -37.3% |
| Dense | 0.9800 | 0.9600 | 0.9852 | 0.9705 | 88% → 88% | 72% → 72% | -28.8% |
| Hybrid | 1.0000 | 0.9800 | 1.0000 | 0.9852 | 92% → 92% | 76% → 76% | -31.7% |

三组 Recall@5、Recall@10 和 Recall@20 均为 100%，因此差异来自相关文档的前部排序和命中片段内容，而不是相关文档完全丢失。BM25 的章节正文完整率由 60% 提高到 100%，跨块完整率由 40% 提高到 60%；重复标题子集则从 100% 降至 80%。Dense 和 Hybrid 没有获得完整证据收益，各有一个相关文档从第一名降至第二名。

严格按“每种召回的整体 nDCG@10 不下降超过 1 个百分点”判断，Markdown 结构分片没有通过 Dense 和 Hybrid 门槛。它的可确认收益是更短的返回上下文、完整章节路径以及 BM25 的排序和证据覆盖改善。25 条样本不足以证明对其他 Markdown 语料的普遍质量提升。

## 5. 相邻扩展结果

下表在同一 Markdown 结构索引上比较 `adjacentChunkCount=0` 与 `1`。

| 召回 | 完整证据变化 | 单命中完整率变化 | 平均 token 变化 | p50 变化 | p95 变化 |
| --- | ---: | ---: | ---: | ---: | ---: |
| BM25 | 84% → 92% | 72% → 80% | 393.9 → 753.8 | 2.68ms → 3.09ms | 3.32ms → 3.72ms |
| Dense | 88% → 88% | 72% → 76% | 442.2 → 747.8 | 14.50ms → 14.88ms | 16.86ms → 16.85ms |
| Hybrid | 92% → 96% | 76% → 80% | 431.3 → 741.4 | 17.79ms → 17.31ms | 19.76ms → 19.22ms |

相邻扩展把 BM25 跨块完整率从 60% 提高到 100%，并把 Hybrid 代码块完整率从 80% 提高到 100%。Dense 只有一条跨块样本从“需要多个命中合并”改善为“单个命中上下文完整”，所以并集覆盖率不变。查询延迟变化很小，主要成本是进入模型上下文的文本增加。

精确重复片段比例为 0% 至 0.06%，说明相邻扩展的 overlap 裁剪和已选邻居去重生效。该指标只识别完全相同的片段，不用于证明语义重复率很低。

## 6. 验收判断

- **结构分片：部分通过。** 功能、章节路径、上下文压缩和 BM25 收益得到验证；Dense 与 Hybrid 的排序门槛未通过，因此没有普遍质量提升结论。
- **相邻扩展：有条件通过。** 完整证据存在 4.0 个百分点的跨召回平均收益，但平均 token 增加 77.0%；它适合质量优先且允许较大上下文的配置，不是无成本优化。
- **向量复用：行为符合预期。** 两种分片策略改变了绝大多数 Dense 输入，只能复用 4 个完全相同输入；同一策略下的局部更新仍使用 T7 已验证的内容寻址复用。
- **阶段结论：** T8 已完成，负结果和成本均保留。后续若要改变分片默认值，应扩大真实语料和查询集，而不是依据本次 25 条样本继续调参。
