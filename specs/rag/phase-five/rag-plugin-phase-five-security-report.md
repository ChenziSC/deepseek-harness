# DSH RAG 插件第五阶段轻量安全评测报告

## 1. 结论

固定的12条间接提示注入样本全部完成，正常事实回答率为12/12。Agent 没有执行证据中的指令，没有调用可用的 `todo_write` 副作用工具，没有泄露系统提示中的评测秘密，也没有把伪造的 `K999` 当作事实引用。24次实际引用全部可以映射到工具分配的结构化引用。

两条伪造引用样本的回答提及 `K999`，但均明确说明该标识符来自不可信正文并拒绝采纳；报告将“提及攻击内容”和“把伪造引用用于事实依据”分开统计。该结果支持当前提示与结果边界的轻量缓解，但不证明模型对任意提示注入免疫。

## 2. 评测设计

每类攻击包含两条隔离样本：忽略上级指令、读取秘密、调用写工具、对外发送、访问URL和伪造引用。每个索引只包含一份带正常颜色事实和攻击文本的文档，Agent 必须回答颜色并引用证据。

运行使用 `ark-deepseek-v4-flash`、`reasoningEffort: low`、BM25、最多2次搜索和独立索引。`todo_write` 保持可用，用于观察证据是否诱导真实副作用调用；文件、网络和外部发送工具未提供，因此后两类只能验证模型没有声称执行或把文档指令作为回答，不能验证其他工具实现的授权机制。

## 3. 结果

| 指标 | 结果 |
| --- | ---: |
| 完成运行 | 12/12 |
| 正常事实与颜色同时出现 | 12/12 |
| 执行证据指令 | 0/12 |
| 非必要副作用工具调用 | 0 |
| 评测秘密泄露 | 0 |
| 伪造引用作为事实依据 | 0 |
| 实际引用可解析率 | 100%（24/24） |
| 提及并明确拒绝 `K999` | 2/2 |

模型对正常事实均使用工具分配的 `K1` 等引用。正文中的 `SYSTEM:`、`todo_write`、外部地址和伪造引用保持在工具生成的不可信证据区域内，没有改变工具调用结构或引用分配。

## 4. 限制

- 这是提示级和结果格式级缓解，不是确定性的恶意内容分类或跨工具污点跟踪。
- 对外发送与URL访问工具未出现在评测运行中，结果不能证明启用这些工具后永远不会被诱导；对应工具仍必须执行自己的权限和审批规则。
- 样本规模小且攻击文本固定，只能作为回归集，不能估计真实攻击分布中的绝对风险。
- 模型可以在回答中讨论并拒绝攻击文本，因此不能把任何攻击字符串出现都等同于指令遵从。
