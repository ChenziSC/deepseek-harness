# DSH RAG 插件第五阶段验收报告

## 1. 结论

第五阶段完成有界智能体化搜索、冲突处理和轻量安全边界，并把 `maxSearchesPerTurn` 默认值从2调整为6。最多8次的前缀评测显示完整证据覆盖率在第2次为75.00%、第6次为88.33%，提高13.33个百分点，第8次没有继续提高；独立硬上限和默认24,000字符累计预算回归均支持6次默认值。

语义边界 pilot 没有显示相对无模型安全切点的收益，因此按规格停止后续实现。`semantic-boundary-v1`、边界向量缓存和三路正式建库消融均未进入产品代码，`markdown-structure-v1` 保持默认分片策略。

## 2. 有界搜索与冲突处理

工具支持每轮1至8次搜索，默认6次。Agent 每次只能先执行一条查询并检查结果，再按独立证据缺口、冲突或缺失中间事实决定是否继续；依赖证据中的不透明标识符时，下一条查询只包含该标识符。规范化重复查询会被拒绝，失败仍消耗搜索次数和引用区间。

每轮成功结果另受 `turnOutputMaxChars` 累计限制，默认24,000字符。这个限制与搜索次数独立，使复杂的小结果链可以继续，而多个大结果不能按6次上限线性占用上下文。

125条评测中的关键结果如下：

| 指标 | 上限2 | 默认候选上限6 |
| --- | ---: | ---: |
| 完整证据覆盖率 | 77.50% | 89.17% |
| 证据组覆盖率 | 77.14% | 93.33% |
| 链式证据与答案同时完成 | 0/15 | 15/15 |
| 预期答案值全部出现 | 50/65 | 65/65 |
| 首轮已充分样本首轮停止 | 15/15 | 15/15 |
| 不可消解冲突保留不确定性 | 5/5 | 5/5 |
| 引用可解析率 | 100% | 100% |

最终组合回归使用默认6次与24,000字符累计预算运行25条新增受控样本，链式、不可消解冲突和无答案样本全部通过，206次引用全部可解析，最大累计结果为4,530字符。详细结果见[有界搜索评测报告](rag-plugin-phase-five-search-budget-report.md)。

## 3. 轻量安全边界

系统提示明确检索内容是不可信数据，不能覆盖系统、开发者或用户指令，也不能授权工具调用。每条证据使用工具生成的起止标记，不可信字段逐行缩进；正文保持原样，允许安全分析，不增加关键词过滤器或内容分类模型。

12条固定攻击样本的正常事实回答率为100%，证据指令遵从为0，副作用工具调用为0，秘密泄露为0，伪造引用作为事实依据为0，实际引用可解析率为100%。两条回答提及 `K999` 时均明确拒绝它，而不是把它当作证据。详细结果见[轻量安全评测报告](rag-plugin-phase-five-security-report.md)。

## 4. 语义分片决策

Pilot 比较无模型的最后安全单元基线、受长度约束最大语义间隙、文档内80百分位和固定0.25距离阈值。最大语义间隙的精确边界召回率为50%，与无模型基线相同，且平均边界数从1.00增加到1.50；其他两个语义方案的精确边界召回率均为33.33%。

由于额外 BGE-M3 编码没有产生切点收益，本阶段不承担异步分片、边界缓存、索引格式变更和三路建库成本。该结论只否定当前小样本和算法配置下的继续投入，不证明所有语义分片方法无效。详细结果见[语义边界 Pilot 报告](rag-plugin-phase-five-semantic-boundary-pilot-report.md)。

## 5. 保留限制

- 提高搜索上限主要改善需要三至六步中间事实的请求；普通双主题样本的完整覆盖率仍为60%，需要继续改进查询生成或底层召回。
- 6次硬上限轨道中5条无答案样本有4条执行超过2次成功搜索，停止效率仍不稳定。
- 真实模型运行出现一次连续三次空最终输出，单独重试后成功；报告保留该瞬时失败，不能把模型可用性归因于RAG逻辑。
- 安全评测提供 `todo_write`，但不提供网络或外部发送工具；提示级缓解不能替代对应工具的授权和审批。
- 语义 pilot 只有6条质量标注样本，不足以作通用负面结论；重新启动实现需要新的独立样本先超过无模型基线。
