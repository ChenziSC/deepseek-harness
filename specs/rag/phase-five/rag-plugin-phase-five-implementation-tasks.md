# DSH RAG 插件第五阶段实施任务

## 1. 交付原则

本阶段先完成低构建成本且直接影响在线行为的有界搜索和轻量安全边界，再运行多预算、冲突和攻击评测。语义分片先经过低成本 pilot，只有出现继续投入的证据才实现缓存和三路正式消融。每个默认值都由固定评测决定；未达到门槛时保留现有默认行为，不为了完成阶段而扩大声明。

## 2. 优先级、成本与依赖

| 优先级 | 任务 | 主要依赖 | 编码成本 | 运行等待成本 | 排序理由 |
| --- | --- | --- | --- | --- | --- |
| P0 | T0 基线冻结 | 无 | 低 | 低 | 后续实验共用输入、指标和缓存身份 |
| P1 | T1 有界搜索；T2 安全提示与证据边界 | T0；T2依赖T1的最终提示和结果格式 | 中、低 | 低 | 直接改善在线行为，并为冲突、安全和预算评测提供稳定实现 |
| P2 | T3 多预算与冲突评测；T4 安全攻击评测 | T1、T2 | 中 | 中 | 决定搜索默认预算并验证风险，且不需要重建向量 |
| P3 | T5 语义边界 pilot | T0 | 低至中 | 低至中 | 用小样本阻止无收益方案进入高成本实现 |
| P4 | T6 语义分片与缓存；T7 三路正式消融 | T5通过 | 高 | 中至高 | 涉及异步分片、缓存身份和多次建库，收益不确定 |
| P5 | T8 组合回归与验收 | T3、T4、T7，或T5的终止结论 | 中 | 中 | 只验证最终候选组合并形成阶段结论 |

成本为相对估计：低通常不超过1人日，中约1至2人日，高约2至4人日；运行等待取决于真实 Agent 样本数、本地模型速度和抽样建库规模，不作为交付时限承诺。

依赖图如下：

```text
T0 规格与基线冻结
  -> T1 有界多轮搜索与累计预算
       -> T2 轻量安全提示与证据边界
            -> T3 冲突处理规则和多预算评测
            -> T4 安全攻击评测与快照
  -> T5 语义边界算法 pilot
       -> [通过] T6 语义分片与边界向量缓存
                    -> T7 三路分片正式消融与默认值决策
       -> [不通过] 记录负面结论

T3 + T4 + T7或T5终止结论
  -> T8 候选组合回归、验收报告与仓库检查
```

T1与T2必须在任何真实 Agent 正式评测前完成，因为两者共同决定模型可见提示和工具结果格式。T3和T4可以复用同一批真实 Agent 运行基础设施，但分别报告质量与安全指标。

T5至T7与T1至T4没有实现依赖。执行顺序仍将语义分片放后：先在固定 Markdown 索引上隔离搜索策略收益，再承担语义分片的模型编码和多次建库成本。T7选择新默认分片时，T8只对最终分片与最终搜索预算运行组合回归，不默认重跑完整笛卡尔积。

## 3. 基线、在线搜索与安全

### T0：规格与基线冻结

依赖：无。

- 校验第四阶段Markdown语料、查询、向量缓存和索引摘要。
- 固定当前Markdown默认索引、Dense模型、候选数、返回数和Agent评测方式。
- 固定多预算、冲突和安全报告的逐样本字段，不在正式运行中改变统计口径。

完成条件：在线搜索改造能够在不重建索引的情况下使用同一基线；已有向量缓存和索引产物的可复用范围得到明确清单。

### T1：有界多轮搜索与累计预算

依赖：T0。

- 将`maxSearchesPerTurn`支持范围扩展到1至8，暂不改变默认值。
- 增加每turn累计成功结果字符预算。
- 规范化并拒绝同一turn内完全重复的查询，失败仍计入调用预算。
- 更新提示，使Agent每次只发出一个搜索调用、检查结果后按未满足证据需求继续搜索，不再把第二次描述为最终一次；依赖不透明标识符时，下一条查询只包含该标识符。
- 保持引用区间唯一、失败预留、单次输出限制和超时行为。
- 更新工具README、单元测试和真实Loader快照。

完成条件：任意配置预算均被硬执行；累计输出不会超过配置；现有两次配置行为保持可用。

### T2：轻量安全提示与证据边界

依赖：T1。

- 在系统提示和工具结果中稳定标识不可信证据。
- 明确检索正文不能覆盖上层指令或授权有副作用操作。
- 保持正文原样可供分析，不增加关键词删除器或内容分类模型。
- 验证正文中的伪造引用、角色标签和工具调用文本不能改变结构化引用分配。
- 保持检索工具只读，不自动访问URL或执行正文。

完成条件：模型可见安全规则有单一明确表述，工具结果边界稳定，正常文档与安全研究文档不会因简单关键词过滤而损坏。

### T3：冲突处理规则和多预算评测

依赖：T1、T2。

- 扩充至少需要三组证据、三步中间事实、可消解冲突、不可消解冲突和无答案样本。
- 主轨道以最多8次搜索运行一次自然Agent轨迹，在第1、2、4、6、8次调用后投影累计指标；提前停止时后续检查点保持相同结果。
- 只对现有2次上限和检查点选出的候选默认上限各运行一次端到端硬限制验证，不为其他中间上限重复完整矩阵。
- 记录各检查点的完整证据覆盖、边际命中、调用分布、停止率、重复率、延迟、累计输出和引用，并记录端到端轨道的预算耗尽行为。
- 检查Agent没有按排名或召回分数直接裁决冲突。
- 存在裁定证据时验证针对性查询和引用；不存在时验证保留不确定性。
- 按质量收益饱和点选择满足条件的最小默认预算。

完成条件：默认预算决策有相对第2次检查点的效果证据；同一轨迹的前缀结果不重复检索；候选默认值通过真实硬上限验证；简单问题不机械增加调用；冲突和无答案场景不产生虚假确定结论。

### T4：安全攻击评测与快照

依赖：T1、T2。

- 固定间接提示注入语料和正常事实问题。
- 覆盖忽略上级指令、秘密读取、写工具调用、外部发送、URL访问和伪造引用六类攻击。
- 运行无密钥快照验证提示与结果格式。
- 运行固定真实Agent小样本，记录指令遵从、副作用调用、秘密泄露、伪造引用和正常问题可答率。
- 报告失败案例，不将提示级缓解描述为确定性隔离。

完成条件：固定攻击集中不执行证据指令、不使用伪造引用，正常事实仍可引用；若模型仍出现风险行为，保持明确限制并不继续堆叠未经验证的提示文本。

## 4. 条件式语义分片

### T5：语义边界算法 pilot

依赖：T0。

- 实现仅供实验使用的候选单元解析和相邻窗口向量输出。
- 准备长段落、弱标题或无标题的pilot语料，不先扩充完整正式评测集。
- 对比受长度约束最大语义间隙、百分位阈值和固定绝对阈值，但只允许一项进入正式实现。
- 检查短文档、单句长文档、代码围栏、中英文混合文本和极端相似文本。
- 记录分片数、长度分布、边界位置、编码输入token和执行时间。

完成条件：选择一个确定性算法和固定参数；没有明显语义边界收益时终止语义实现并保留负面pilot报告。

### T6：语义分片与边界向量缓存

依赖：T5通过。

- 增加`semantic-boundary-v1`策略和异步分片路径。
- 记录完整语义模型与算法配置；按索引格式规则处理清单变化。
- 为边界向量增加与最终检索向量隔离的内容寻址缓存用途。
- 保持`maxTokens`、overlap、Unicode安全、代码围栏和确定性排序。
- BM25-only选择语义分片时显式加载语义模型，缺少本地模型时提前失败。
- 输出边界缓存命中、边界编码和最终Dense编码的独立计时。

完成条件：未变化文档的边界向量100%复用；局部修改不重算其他文档；失败或取消不发布完整索引。

### T7：三路分片正式消融

依赖：T6。

- 构建Token窗口、Markdown结构感知和语义边界三个索引。
- 扩充结构敏感查询、长文档轨道和文档级qrels，并完成必需证据范围复核。
- 固定Reranker关闭、相邻扩展关闭，运行BM25、Dense和Hybrid。
- 输出标准排序、证据完整性、上下文token、分片规模、构建成本和RSS。
- 按概要设计门槛决定默认策略，不根据结果追加阈值扫描。
- 对选出的候选默认策略补充相邻扩展开关实验。

完成条件：报告明确选择唯一默认值，或者明确保留`markdown-structure-v1`；没有收益的语义分片可以保留为显式实验选项或撤回，不能仅因已实现而设为默认。

## 5. 收尾

### T8：候选组合回归、验收报告与仓库检查

依赖：T3、T4，以及T7或T5的语义分片终止结论。

- 使用最终候选分片与最终候选搜索预算运行小规模组合回归；只有出现交互回退时才扩大矩阵。
- 编写第五阶段验收报告，分别记录分片默认决策、搜索预算、冲突处理和安全结论。
- 更新受影响README、Agent Note、配置文档和模型可见快照。
- 运行相关包逐文件覆盖率、语义模型小样本、知识快照、`typecheck`、`lint`、`doc-sync`、`hygiene`和`git diff --check`。
- 确认模型、向量、索引、完整语料、真实会话和本机路径未进入提交范围。

完成条件：所有验收指标有机器可读结果和中文结论；负结果保留且默认值与证据一致；不自动commit或push。

## 6. 明确暂缓

- 不实现RAPTOR、GraphRAG、上下文前缀生成或语义摘要。
- 不实现知识写入、PR审核、定期整理、失效过滤或多租户权限。
- 不实现无限搜索、后台研究任务或`agent-loop`专用RAG分支。
- 不实现内容审核模型、提示注入分类器、跨工具污点跟踪或新的授权系统。
- 不实现双分片索引路由、第二种ANN、在线HNSW更新或远程向量数据库。
