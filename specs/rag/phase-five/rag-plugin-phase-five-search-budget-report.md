# DSH RAG 插件第五阶段有界搜索评测报告

## 1. 结论

`maxSearchesPerTurn` 的默认值选择为 **6**。最多8次的单轨迹前缀评测在第2次调用时完整证据覆盖率为75.00%，第6次为88.33%，提高13.33个百分点；第8次仍为88.33%，说明第6次之后没有新增完整覆盖。独立硬上限运行中，6次上限的完整证据覆盖率为89.17%，比2次上限的77.50%提高11.67个百分点，15条链式样本从0/15提高到15/15。

这项收益只证明有限搜索预算从2增至6能够完成本评测中的三至六步证据链，不表示每个请求都应执行6次搜索。15条首轮已充分样本在三个硬上限轨道中均为15/15首轮停止。`turnOutputMaxChars` 继续独立限制累计结果文本，防止默认搜索次数增加后上下文无界增长。

## 2. 输入与方法

评测包含125条请求：第四阶段的100条单主题、双主题、中间事实、首轮充分和可消解冲突样本；第五阶段新增15条三至六步链式样本、5条不可消解冲突样本和5条无答案样本。T2Ranking 样本使用既有10k Dense Exact索引，受控样本各自使用隔离的BM25索引，不重新构建大规模向量。

主轨道允许最多8次搜索，并从同一条自然 Agent 轨迹投影第1、2、4、6、8次调用后的累计证据。另行运行硬上限2和6，验证预算变化会影响的查询决策、拒绝行为与最终回答。三个硬上限轨道均使用 `ark-deepseek-v4-flash`、`reasoningEffort: low`、每次最多10条结果、Reranker `off` 和96,000字符实验累计预算；该高累计预算用于隔离搜索次数变量，不替代产品默认的24,000字符限制。

## 3. 单轨迹前缀结果

| 调用检查点 | 完整证据覆盖率 | 证据组覆盖率 | 相对上一检查点新增完整样本 |
| ---: | ---: | ---: | ---: |
| 1 | 34.17% | 43.33% | 41 |
| 2 | 75.00% | 75.71% | 49 |
| 4 | 84.17% | 88.57% | 11 |
| 6 | 88.33% | 93.33% | 5 |
| 8 | 88.33% | 93.33% | 0 |

第4次相对第2次仍有9.17个百分点完整覆盖收益，第6次再增加4.17个百分点；第6至第8次没有收益。按照“相对第2次至少提高10个百分点、后续收益低于2个百分点”的预设门槛，候选值为6，而不是4或8。

## 4. 硬上限验证

| 指标 | 上限2 | 上限6 | 上限8参考轨道 |
| --- | ---: | ---: | ---: |
| 完整证据覆盖率 | 77.50% | 89.17% | 88.33% |
| 证据组覆盖率 | 77.14% | 93.33% | 93.33% |
| 预期答案值全部出现 | 50/65 | 65/65 | 65/65 |
| 链式证据与答案同时完成 | 0/15 | 15/15 | 15/15 |
| 首轮已充分样本首轮停止 | 15/15 | 15/15 | 15/15 |
| 不可消解冲突保留不确定性 | 5/5 | 5/5 | 5/5 |
| 无答案样本不猜测 | 5/5 | 5/5 | 5/5 |
| 引用可解析率 | 100% | 100% | 100% |
| 成功调用不超过硬上限 | 100% | 100% | 100% |
| 预算拒绝后的不确定性说明 | 2/2 | 4/4 | 无预算拒绝 |

6次上限的平均端到端时间为13.09秒，2次上限为11.93秒，增加9.65%；累计输入 token 总量从705,081增至856,831，增加21.52%。质量收益主要来自链式样本，普通双主题样本的完整覆盖率在三个轨道中均为60%，因此提高预算不能替代查询生成或底层召回改进。

最终组合回归使用实际默认值6和24,000字符累计预算运行25条第五阶段受控样本。15条链式样本全部完成，5条不可消解冲突全部保留不确定性，5条无答案样本全部未猜测，206次引用全部可解析；单轮累计渲染文本最大为4,530字符，没有触发累计输出限制。3次越过搜索上限的尝试均被拒绝，最终回答均说明不确定性。

## 5. 停止与失败分析

6次上限下118/125条请求在达到上限前停止；15条首轮充分样本全部只搜索一次。5条无答案样本分别执行2、3、4、4、5次成功搜索，其中3条随后尝试超过预算并被拒绝，说明无答案停止效率仍不稳定。最大8次轨道出现2次规范化重复查询，均被工具拒绝，没有重复执行检索。

6次轨道的 `retrieval-decision-single-024` 连续三次运行得到空最终输出；保留该失败记录后单独重试成功。该问题没有改变证据覆盖结论，但说明真实模型运行仍存在与检索预算无关的偶发完成失败，后续组合回归必须保留失败计数。

## 6. 产品策略

- 默认最多6次搜索，但提示要求逐次执行，并只在独立证据缺口、冲突或中间事实缺失时继续。
- 累计结果文本默认仍为24,000字符；更多调用次数不等于允许更多上下文。
- Agent 无法提出新的针对性查询、证据已充分或预算耗尽时停止。
- 无答案场景的额外搜索浪费仍是已知限制，不增加第7或第8次预算。
- 6次默认值已通过与24,000字符累计预算组合的受控回归。

机器可读结果见 [`data/bounded-search-evaluation-summary.json`](data/bounded-search-evaluation-summary.json)。原始模型输出、会话和索引保留在 `.cache`，不进入提交范围。
