# DSH RAG 插件第三阶段实施任务

## 1. 交付原则

本阶段按依赖顺序交付，不把四项能力拆成互不相干的并行实现。每项任务完成时运行定向测试；全部实现后再运行三包 coverage、真实组合快照、数据集评测和仓库级文档检查。

## 2. 依赖图

```text
T0 规格冻结
  -> T1 索引基础升级
       -> T2 结构分片与相邻扩展
       -> T3 查询策略自动路由
            -> T4 自适应 Reranker
                 -> T5 最多两轮 Agentic 检索与组合快照
                      -> T6 消融评测与验收报告
```

T2 与 T3 在 T1 完成后可以独立编码，但二者都会修改清单、SQLite 和提供方读取路径，单人实施时顺序完成可以减少冲突。T4 依赖 T3 引入的两阶段执行计划。T5 的硬限制可独立实现，但模型提示和快照依赖前三项的最终工具语义，因此最后收敛。

## 3. 任务清单

### T0：规格冻结

依赖：无。

- 确认四项唯一范围、默认值、非目标和术语。
- 确认索引格式升级、请求态 `auto`、`rerank: auto` 和两轮限制语义。
- 确认单项消融与组合验收方式。

完成条件：概要设计、详细设计和实施任务三份中文文档互相一致。

### T1：索引基础升级

依赖：T0。

- 索引格式升级到 3，SQLite schema 升级到 2。
- `chunks` 增加 `section_path`。
- 清单增加 `chunking.strategy` 和 `corpus.scriptProfile`。
- 构建期流式统计 Latin/CJK 字符，不额外保留全量语料。
- 更新索引加载校验、README、测试 fixture 和示例微型索引。

完成条件：新索引可构建、校验和加载；旧格式被明确拒绝；BM25-only、Exact-only 和 HNSW-only 路径均通过定向测试。

### T2：结构感知分片与相邻扩展

依赖：T1。

- 识别 ATX 标题层级和 fenced code block。
- 实现结构、段落、句子和 token 上限的边界优先级。
- 将标题路径加入 BM25 与 Dense 索引文本。
- 最终排序后读取同文档前后各一块，去除 overlap 重复。
- 扩展 `KnowledgeHit` 和工具输出，保证命中块优先占用字符预算。

完成条件：Markdown fixture 覆盖标题、围栏、超长结构、文档边界、相邻命中去重和输出裁剪；邻居不改变 `maxResults` 与离线召回计算。

### T3：查询策略自动路由

依赖：T1。

- 请求态 `KnowledgeRetrieval` 增加 `auto`，结果态保持具体策略。
- 默认召回偏好改为 `auto`。
- 实现精确词项、跨脚本和普通自然语言路由规则。
- 实现受 `allowedRetrieval` 约束的确定性自动选择。
- 工具 schema 和提示词支持省略或显式 `auto`，显式具体策略继续覆盖。

完成条件：精确标识符、普通查询、CJK→Latin、Latin→CJK、mixed、neutral、显式覆盖和受限允许集合均有测试；结果报告实际策略。

### T4：自适应 Reranker

依赖：T3。

- 策略解析返回召回执行计划，而不是提前把 `auto` 变成布尔值。
- 召回后按前两名归一化分差决定是否重排。
- 增加默认 `0.15` 的提供方配置和边界校验。
- 保持 `on` 强制、`off` 禁止、字段省略使用部署默认。
- 评测输出增加自适应触发次数与比例。

完成条件：0/1 候选、强分差、弱分差、强制开启、强制关闭、禁用策略和取消路径均通过；结果布尔值反映实际执行。

### T5：最多两轮 Agentic 检索

依赖：T2、T3、T4 的模型可见语义稳定。

- 工具配置增加默认且最大为 2 的 `maxSearchesPerTurn`。
- 按调用 agent 和当前持久 turn 计数，并发调用同步占用名额。
- 参数校验失败不计数，进入提供方后的成功或失败调用计数。
- 更新系统提示，要求一次优先、必要时互补二次、两次后停止。
- 更新真实 Loader 快照和工具 README。

完成条件：同 turn 第一次、第二次、第三次、新 turn 清零、并发、提供方失败和无 agent 直接调用均有测试；不修改 agent loop。

### T6：消融评测与验收

依赖：T2、T3、T4、T5。

- 结构分片：在 Markdown fixture、SciFact 与 MLDR 样本上比较基线和结构分片。
- 自动路由：在精确词项 fixture、普通查询和 MLQA Retrieval 跨语言样本上比较固定策略。
- 自适应重排：与 `off`、`on` 比较质量、触发率和 p50/p95。
- 两轮检索：使用双证据 fixture 验证首轮不足、第二轮补充和停止条件。
- 生成第三阶段中文验收报告，记录已解决问题、剩余限制和推荐后续方向。

完成条件：三包相关 coverage 每文件 100%，知识快照、`typecheck`、`lint`、`doc-sync` 和 `git diff --check` 通过；真实模型或数据集受本机资源限制未完成时必须在报告中明确标注，不能用 fixture 指标替代。
